# 1:1 WebRTC Calls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Audio and video calls between two users of the same private chat on one server: WebRTC media peer-to-peer with a TURN fallback, signaling over the existing SSE hub plus REST, call state in process memory.

**Architecture:** A new `backend/calls` package owns an in-memory registry of calls (state transitions, timers, per-user indexes) and knows nothing about HTTP or the database. `service/calls.go` owns the rules (who may call whom, busy checks, event fan-out, push). `transport/calls.go` exposes six endpoints. On the client, `frontend/src/calls/callManager.ts` owns the `RTCPeerConnection` and the media tracks, `callState.ts` holds the state the UI renders, and `handleCallEvent.ts` maps SSE events to actions. The existing SSE hub carries the signaling; the server never sees media.

**Tech Stack:** Go 1.26, Huma v2, `sse.Hub` for fan-out, GORM/SQLite for the store, React 19, Mantine 9, vitest + jsdom, Playwright for e2e.

**Spec:** `docs/superpowers/specs/2026-10-20-calls-1to1-design.md`

```go
package ids

import (
	"crypto/rand"
	"encoding/hex"

// Generate returns a random 128-bit identifier in hex.
func Generate() string {
	buf := make([]byte, 16)
	if _, err := rand.Read(buf); err != nil {

	return hex.EncodeToString(buf)
}
```

```go
// warnAboutICE reports a configuration that limits the calls: without a TURN
// server a part of the networks cannot connect at all, and a static TURN
// password makes the relay usable by everyone who can open the site.
func warnAboutICE(cfg *config.Config) {
	if len(cfg.ICE.TURN) == 0 {
		slog.Warn("no TURN server configured: calls will not connect in networks behind a symmetric NAT")

		return

	for _, turn := range cfg.ICE.TURN {

		}
	}
}
```

`backend/calls/calls.go`:

```go
// Package calls keeps the state of the ongoing calls in memory. The package
// knows nothing about HTTP or the database: the rules live in the service
// layer, the transport only maps HTTP to the service.
package calls

import (
	"errors"
	"sync"
	"time"

	"fast_chat/internal/ids"
)

type State string

const (
	StateRinging State = "ringing"
	StateActive  State = "active"
	StateEnded   State = "ended"
)

// Reasons a call can end with. Only the server sets timeout and rejected;
// hangup and peer-left come from the client, and only peer-left is accepted
// from the request body (see the service layer).
const (
	ReasonHangup   = "hangup"
	ReasonRejected = "rejected"
	ReasonTimeout  = "timeout"
	ReasonPeerLeft = "peer-left"
)

const (
	// RingingTimeout is how long the callee has to answer.
	RingingTimeout = 45 * time.Second
	// ActiveTTL is the hard limit for an active call. It is the safety net
	// for a call whose participants never came back.
	ActiveTTL = 4 * time.Hour
	// EndedTTL is how long an ended call is kept, so a client that returns
	// later can still learn the final state of the call.
	EndedTTL = 10 * time.Minute
)

var (
	ErrBusy       = errors.New("user is already in a call")
	ErrNotFound   = errors.New("call not found")
	ErrNotRinging = errors.New("call is not ringing")
	ErrEnded      = errors.New("call is already ended")
)

// Call is one conversation. The SDP is kept only while it can still be used:
// the offer until the call is accepted, the answer until it ends.
type Call struct {
	ID        string
	CallerID  string
	CalleeID  string
	ChatID    string
	State     State
	Offer     string
	Answer    string
	CreatedAt time.Time
	ExpiresAt time.Time
	EndedAt   time.Time
	Reason    string
}

// Participant reports whether the user takes part in the call.
func (c *Call) Participant(userID string) bool {
	return c.CallerID == userID || c.CalleeID == userID
}

// Peer returns the other side of the call.
func (c *Call) Peer(userID string) string {
	if c.CallerID == userID {
		return c.CalleeID
	}

	return c.CallerID
}

// Manager is the registry of calls. Every operation that changes the state
// runs under one lock, so a busy check and the change it guards cannot be
// interleaved.
type Manager struct {
	mu       sync.Mutex
	calls    map[string]*Call
	active   map[string]string // userID -> callID
	recent   map[string]string // userID -> last ended callID
	isOnline func(userID string) bool
	now      func() time.Time
}

// NewManager builds a registry. isOnline reports whether a user is
// connected; the registry calls it outside its lock, never while holding it.
func NewManager(isOnline func(userID string) bool) *Manager {
	if isOnline == nil {
		isOnline = func(string) bool { return false }
	}

	return &Manager{
		calls:    make(map[string]*Call),
		active:   make(map[string]string),
		recent:   make(map[string]string),
		isOnline: isOnline,
		now:      time.Now,
	}
}

// CreateCall registers a new call. It fails when either side is already in
// a call.
func (m *Manager) CreateCall(callerID, calleeID, chatID, offer string) (*Call, error) {
	m.mu.Lock()
	defer m.mu.Unlock()

	if m.active[callerID] != "" || m.active[calleeID] != "" {
		return nil, ErrBusy
	}

	now := m.now()
	call := &Call{
		ID:        ids.Generate(),
		CallerID:  callerID,
		CalleeID:  calleeID,
		ChatID:    chatID,
		State:     StateRinging,
		Offer:     offer,
		CreatedAt: now,
		ExpiresAt: now.Add(RingingTimeout),
	}

	m.calls[call.ID] = call
	m.active[callerID] = call.ID
	m.active[calleeID] = call.ID

	return call, nil
}

// AcceptCall moves a ringing call to active. Only the first accept wins.
func (m *Manager) AcceptCall(callID, answer string) (*Call, error) {
	m.mu.Lock()
	defer m.mu.Unlock()

	call, ok := m.calls[callID]
	if !ok {
		return nil, ErrNotFound
	}

	if call.State == StateEnded {
		return nil, ErrEnded
	}

	if call.State != StateRinging {
		return nil, ErrNotRinging
	}

	call.State = StateActive
	call.Answer = answer
	call.Offer = ""
	call.ExpiresAt = m.now().Add(ActiveTTL)

	return call, nil
}

// EndCall finishes a call with the given reason.
func (m *Manager) EndCall(callID, reason string) error {
	m.mu.Lock()
	defer m.mu.Unlock()

	call, ok := m.calls[callID]
	if !ok {
		return ErrNotFound
	}

	if call.State == StateEnded {
		return nil
	}

	call.State = StateEnded
	call.Reason = reason
	call.EndedAt = m.now()
	call.Offer = ""
	call.Answer = ""
	call.ExpiresAt = time.Time{}

	delete(m.active, call.CallerID)
	delete(m.active, call.CalleeID)
	m.recent[call.CallerID] = call.ID
	m.recent[call.CalleeID] = call.ID

	return nil
}

// Get returns a call by its identifier.
func (m *Manager) Get(callID string) (*Call, bool) {
	m.mu.Lock()
	defer m.mu.Unlock()

	call, ok := m.calls[callID]

	return call, ok
}

// Current returns the call the user is in, or the last one they were in.
func (m *Manager) Current(userID string) (*Call, bool) {
	m.mu.Lock()
	defer m.mu.Unlock()

	if id := m.active[userID]; id != "" {
		call, ok := m.calls[id]
		if ok {
			return call, true
		}
	}

	if id := m.recent[userID]; id != "" {
		call, ok := m.calls[id]
		if ok {
			return call, true
		}
	}

	return nil, false
}

// Sweep ends the calls that cannot go on and forgets the ones that are old
// enough. It is called from a background loop.
func (m *Manager) Sweep() {
	m.mu.Lock()

	now := m.now()
	var expiredRinging []string
	var staleActive []string

	for _, call := range m.calls {
		switch call.State {
		case StateRinging:
			if !now.Before(call.ExpiresAt) {
				expiredRinging = append(expiredRinging, call.ID)
			}
		case StateActive:
			if now.Sub(call.CreatedAt) > ActiveTTL {
				staleActive = append(staleActive, call.ID)
			}
		}
	}

	m.mu.Unlock()

	// The presence check runs outside the lock: it may reach the database,
	// and the lock is waited for by the call endpoints.
	for _, id := range expiredRinging {
		_ = m.EndCall(id, ReasonTimeout)
	}

	for _, id := range staleActive {
		m.mu.Lock()
		call, ok := m.calls[id]
		m.mu.Unlock()

		if !ok || call.State != StateActive {
			continue
		}

		if !m.isOnline(call.CallerID) && !m.isOnline(call.CalleeID) {
			_ = m.EndCall(id, ReasonPeerLeft)
		}
	}

	m.mu.Lock()
	defer m.mu.Unlock()

	for id, call := range m.calls {
		if call.State == StateEnded && now.Sub(call.EndedAt) > EndedTTL {
			delete(m.calls, id)
		}
	}
}

// Close ends every call. It runs before the SSE hub is closed, so the
// clients still receive the final state.
func (m *Manager) Close() {
	m.mu.Lock()
	defer m.mu.Unlock()

	for id, call := range m.calls {
		if call.State == StateEnded {
			continue
		}

		call.State = StateEnded
		call.Reason = ReasonPeerLeft
		call.EndedAt = m.now()
		call.Offer = ""
		call.Answer = ""
		delete(m.calls, id)
	}
}
```

```go
package service

import (
	"context"
	"errors"
	"time"

	"fast_chat/calls"
	"fast_chat/sse"
)

var (
	ErrCallNotFound   = errors.New("call not found")
	ErrNotParticipant = errors.New("not a participant of the call")
	ErrNotPrivateChat = errors.New("calls are only possible in a private chat")
	ErrChatWithSelf   = errors.New("cannot call yourself")
	ErrRemoteCallee   = errors.New("calls between servers are not supported")
)

// SetCallManager attaches the call registry to the service.
func (s *Service) SetCallManager(manager *calls.Manager) {
	s.calls = manager
}

// CallManager returns the call registry.
func (s *Service) CallManager() *calls.Manager {
	return s.calls
}

// StartCall registers a call in a private chat and notifies the callee.
func (s *Service) StartCall(ctx context.Context, callerID, chatID, offer string) (*calls.Call, error) {
	if s.calls == nil {
		return nil, ErrCallNotFound
	}

	chat, ok := s.store.GetChat(ctx, chatID)
	if !ok {
		return nil, ErrChatNotFound
	}

	if chat.Type != "private" || len(chat.Members) != 2 {
		return nil, ErrNotPrivateChat
	}

	calleeID := ""
	for _, member := range chat.Members {
		if member == callerID {
			continue
		}

		calleeID = member
	}

	if calleeID == "" {
		return nil, ErrChatWithSelf
	}

	// A callee from another server cannot be reached: the signaling has no
	// route to that server.
	if remote := RemoteServerFromID(calleeID); remote != "" && remote != s.cfg.Server.Domain {
		return nil, ErrRemoteCallee
	}

	call, err := s.calls.CreateCall(callerID, calleeID, chatID, offer)
	if err != nil {
		return nil, err
	}

	s.hub.Send(calleeID, sse.Event{Event: "call_incoming", Data: map[string]any{
		"callId":    call.ID,
		"from":      map[string]string{"id": callerID, "nick": s.nickOf(ctx, callerID)},
		"chatId":    chatID,
		"offer":     offer,
		"expiresAt": call.ExpiresAt.Format(time.RFC3339),
	}})

	s.sendCallPush(ctx, call)

	return call, nil
}

// AcceptCall accepts a ringing call. The caller receives the answer, the
// callee receives the identifier only, so the other tabs of the callee can
// close their window.
func (s *Service) AcceptCall(ctx context.Context, userID, callID, answer string) (*calls.Call, error) {
	call, err := s.participantCall(callID, userID)
	if err != nil {
		return nil, err
	}

	if call.CalleeID != userID {
		return nil, ErrNotParticipant
	}

	accepted, err := s.calls.AcceptCall(callID, answer)
	if err != nil {
		return nil, err
	}

	s.hub.Send(accepted.CallerID, sse.Event{Event: "call_accepted", Data: map[string]any{
		"callId": accepted.ID,
		"answer": answer,
	}})

	s.hub.Send(accepted.CalleeID, sse.Event{Event: "call_accepted", Data: map[string]any{
		"callId": accepted.ID,
	}})

	return accepted, nil
}

// RejectCall declines a ringing call.
func (s *Service) RejectCall(ctx context.Context, userID, callID string) error {
	call, err := s.participantCall(callID, userID)
	if err != nil {
		return err
	}

	if call.CallerID != userID {
		return ErrNotParticipant
	}

	if err := s.calls.EndCall(callID, calls.ReasonRejected); err != nil {
		return err
	}

	s.notifyEnded(call, calls.ReasonRejected)

	return nil
}

// HangupCall ends a call. The reason may refine the outcome, but the client
// cannot choose it: only peer-left is accepted, everything else is a plain
// hangup.
func (s *Service) HangupCall(ctx context.Context, userID, callID, reason string) error {
	call, err := s.participantCall(callID, userID)
	if err != nil {
		return err
	}

	if reason != calls.ReasonPeerLeft {
		reason = calls.ReasonHangup
	}

	if err := s.calls.EndCall(callID, reason); err != nil {
		return err
	}

	s.notifyEnded(call, reason)

	return nil
}

// SendIce forwards an ICE candidate to the other side.
func (s *Service) SendIce(ctx context.Context, userID, callID, candidate string) error {
	call, err := s.participantCall(callID, userID)
	if err != nil {
		return err
	}

	s.hub.Send(call.Peer(userID), sse.Event{Event: "call_ice", Data: map[string]any{
		"callId":    call.ID,
		"candidate": candidate,
	}})

	return nil
}

// CurrentCall returns the call the user is in, or the last one.
func (s *Service) CurrentCall(ctx context.Context, userID string) (*calls.Call, bool) {
	if s.calls == nil {
		return nil, false
	}

	return s.calls.Current(userID)
}

// participantCall loads a call and checks that the user takes part in it.
func (s *Service) participantCall(callID, userID string) (*calls.Call, error) {
	if s.calls == nil {
		return nil, ErrCallNotFound
	}

	call, ok := s.calls.Get(callID)
	if !ok {
		return nil, ErrCallNotFound
	}

	if !call.Participant(userID) {
		return nil, ErrNotParticipant
	}

	return call, nil
}

// notifyEnded tells both sides that the call is over.
func (s *Service) notifyEnded(call *calls.Call, reason string) {
	data := map[string]any{"callId": call.ID, "reason": reason}

	s.hub.Send(call.CallerID, sse.Event{Event: "call_ended", Data: data})
	s.hub.Send(call.CalleeID, sse.Event{Event: "call_ended", Data: data})
}

// nickOf returns the display name of a user, or the identifier when the user
// is unknown.
func (s *Service) nickOf(ctx context.Context, userID string) string {
	user, ok := s.store.GetUserByID(ctx, userID)
	if !ok {
		return userID
	}

	return user.Nick
}
```

```go
type callPushPayload struct {
	Title string        `json:"title"`
	Tag   string        `json:"tag"`
	Data  callPushData  `json:"data"`
}

type callPushData struct {
	CallID   string `json:"callId"`
	ChatID   string `json:"chatId"`
	FromID   string `json:"fromId"`
	FromNick string `json:"fromNick"`
}

// sendCallPush notifies an offline callee. Every call gets its own tag, so
// two calls in a row do not collapse into one notification.
func (s *Service) sendCallPush(ctx context.Context, call *calls.Call) {
	if s.push == nil || s.store.IsOnline(call.CalleeID) {
		return
	}

	subs, err := s.store.GetPushSubscriptionsByUser(ctx, call.CalleeID)
	if err != nil || len(subs) == 0 {
		return
	}

	payload, err := json.Marshal(callPushPayload{
		Title: s.nickOf(ctx, call.CallerID),
		Tag:   "call-" + call.ID,
		Data: callPushData{
			CallID:   call.ID,
			ChatID:   call.ChatID,
			FromID:   call.CallerID,
			FromNick: s.nickOf(ctx, call.CallerID),
		},
	})
	if err != nil {
		return
	}

	go s.push.SendToUser(payload, subs)
}
```

```go
func (m *Manager) Run(ctx context.Context, interval time.Duration) {
	ticker := time.NewTicker(interval)
```

```ts
import type { ICEConfig } from "../types/api.ts";
import type { CallApi, CallState } from "./callTypes.ts";

const MEDIA_CONSTRAINTS: MediaStreamConstraints = {
	audio: true,
	video: true,
};

export interface CallManager {
	start(chatId: string): Promise<void>;
	accept(answer: string): Promise<void>;
	reject(): Promise<void>;
	hangup(reason?: string): Promise<void>;
	handleIncoming(payload: unknown): void;
	handleAccepted(payload: unknown): void;
	handleEnded(payload: unknown): void;
	handleIce(payload: unknown): void;
	end(): void;
	state(): CallState;
}

export function createCallManager(
	api: CallApi,
	iceServers: RTCIceServer[] = [],
): CallManager {
	let phase: CallState["phase"] = "idle";
	let iceServers: RTCIceServer[] = [];
	let callId: string | undefined;
	let chatId: string | undefined;
	let peerId: string | undefined;
	let peerNick: string | undefined;
	let localStream: MediaStream | undefined;
	let remoteStream: MediaStream | undefined;
	let peer: RTCPeerConnection | undefined;
	let pendingCandidates: string[] = [];
	let muted = false;
	let cameraOn = true;

	function reset() {
		phase = "idle";
		callId = undefined;
		chatId = undefined;
		peerId = undefined;
		peerNick = undefined;
		localStream = undefined;
		remoteStream = undefined;
		peer = undefined;
		pendingCandidates = [];
		muted = false;
		cameraOn = true;
	}

	function createPeer(): RTCPeerConnection {
		const connection = new RTCPeerConnection({ iceServers });
		connection.onicecandidate = (event) => {
			if (event.candidate && callId) {
				void api.sendCallIce(api.token, callId, event.candidate.toJSON());
			}
		};

		return connection;
	}

	async function loadIceServers(): Promise<RTCIceServer[]> {
		try {
			const config = await api.getIceServers(api.token);

			return [
				...config.stun.map((url) => ({ urls: url })),
				...config.turn.map((turn) => ({
					urls: turn.urls,
					username: turn.username,
					credential: turn.credential,
				})),
			];
		} catch {
			return [];
		}
	}

	async function acquireMedia(): Promise<MediaStream> {
		try {
			return await navigator.mediaDevices.getUserMedia(MEDIA_CONSTRAINTS);
		} catch {
			// No camera: the call continues with the microphone only.
			return await navigator.mediaDevices.getUserMedia({ audio: true });
		}
	}

	async function flushCandidates() {
		if (!peer) return;

		for (const candidate of pendingCandidates) {
			await peer.addIceCandidate(candidate);
		}

		pendingCandidates = [];
	}

	return {
		async start(targetChatId: string) {
			iceServers = await loadIceServers();
			localStream = await acquireMedia();
			peer = createPeer();


			for (const track of localStream.getTracks()) {
				peer.addTrack(track, localStream);
			}

			const offer = await peer.createOffer();
			await peer.setLocalDescription(offer);

			const result = await api.startCall(
				api.token,
				targetChatId,
				offer.sdp ?? "",
			);

			callId = result.callId;
			chatId = targetChatId;
			phase = "outgoing";
		},

		async accept(answer: string) {
			if (!peer || !callId) return;

			await peer.setRemoteDescription({ type: "answer", sdp: answer });
			await flushCandidates();
			await api.acceptCall(api.token, callId, answer);
			phase = "active";
		},

		async reject() {
			if (!callId) return;

			await api.rejectCall(api.token, callId);
			this.end();
		},

		async hangup(reason?: string) {
			if (!callId) return;

			await api.hangupCall(api.token, callId, reason);
			this.end();
		},

		handleIncoming(payload: unknown) {
			const data = payload as {
				callId: string;
				chatId: string;
				offer: string;
				from: { id: string; nick: string };
			};

			callId = data.callId;
			chatId = data.chatId;
			peerId = data.from.id;
			peerNick = data.from.nick;
			phase = "incoming";
			pendingCandidates = [];

			void (async () => {
				localStream = await acquireMedia();
				peer = createPeer();

				for (const track of localStream.getTracks()) {
					peer.addTrack(track, localStream);
				}

				peer.ontrack = (event) => {
					remoteStream = event.streams[0];
				};

				await peer.setRemoteDescription({
					type: "offer",
					sdp: data.offer,
				});
				await flushCandidates();

				const answer = await peer.createAnswer();
				await peer.setLocalDescription(answer);
				await api.acceptCall(api.token, data.callId, answer.sdp ?? "");
				phase = "active";
			})();
		},

		handleAccepted(payload: unknown) {
			const data = payload as { callId: string; answer?: string };

			if (data.answer === undefined) {
				// Another tab of the callee accepted: this tab has nothing
				// to do but close its window.
				if (phase === "incoming") this.end();

				return;
			}

			void (async () => {
				if (!peer) return;

				await peer.setRemoteDescription({
					type: "answer",
					sdp: data.answer,
				});
				await flushCandidates();
				phase = "active";
			})();
		},

		handleEnded(payload: unknown) {
			const data = payload as { reason?: string };
			phase = "ended";
			this.end();
		},

		handleIce(payload: unknown) {
			const data = payload as { candidate: string };

			if (!peer) {
				pendingCandidates.push(data.candidate);

				return;
			}

			void peer.addIceCandidate(data.candidate);
		},

		end() {
			for (const track of localStream?.getTracks() ?? []) {
				track.stop();
			}

			peer?.close();
			reset();
		},

		state() {
			return {
				phase,
				callId,
				chatId,
				peerId,
				peerNick,
				reason: undefined,
				localStream,
				remoteStream,
				muted,
				cameraOn,
			};
		},
	};
}
```

```ts
// handleCallEvent routes a signaling event to the manager. Unknown events
// are ignored: the SSE stream carries the whole domain.
export function handleCallEvent(
	manager: CallManager,
	event: string,
	data: unknown,
): void {
	switch (event) {
		case "call_incoming":
			manager.handleIncoming(data);
			return;
		case "call_accepted":
			manager.handleAccepted(data);
			return;
		case "call_ended":
			manager.handleEnded(data);
			return;
		case "call_ice":
			manager.handleIce(data);
			return;

			return;

}
```

```ts
import { useSyncExternalStore } from "react";
import type { CallManager } from "./callManager.ts";
import type { CallState } from "./callTypes.ts";

type Listener = () => void;

// callStore keeps the state of the call and notifies the subscribers when
// it changes. The manager stays the owner of the connection; the store only
// mirrors what the interface needs.
export function createCallStore(manager: CallManager) {
	const listeners = new Set<Listener>();
	let snapshot: CallState = manager.state();

	function refresh() {
		snapshot = manager.state();

		for (const listener of listeners) {
			listener();
		}
	}

	return {
		subscribe(listener: Listener) {
			listeners.add(listener);

			return () => {
				listeners.delete(listener);
			};
		},
		getSnapshot() {
			return snapshot;
		},
		refresh,
	};
}

// useCallState subscribes a component to the state of the call.
export function useCallState(store: ReturnType<typeof createCallStore>): CallState {
	return useSyncExternalStore(
		store.subscribe,
		store.getSnapshot,
		store.getSnapshot,
	);
}
```

```ts
import { useCallback, useMemo, useRef, useSyncExternalStore } from "react";
import {
	acceptCall,
	getCurrentCall,
	getIceServers,
	hangupCall,
	rejectCall,
	sendCallIce,
	startCall,
} from "../api.ts";
import { createCallManager, type CallManager } from "../calls/callManager.ts";
import { createCallStore } from "../calls/callState.ts";

export function useCall(token: string | undefined) {
	const managerRef = useRef<CallManager | null>(null);

	const manager = useMemo(() => {
		if (token === undefined) return null;

		if (managerRef.current === null) {
			managerRef.current = createCallManager(
				{
					token,
					getIceServers,
					startCall,
					acceptCall,
					rejectCall,
					hangupCall,
					sendCallIce,
				},
			);
		}

		return managerRef.current;
	}, [token]);

	const store = useMemo(
		() => (manager === null ? null : createCallStore(manager)),
		[manager],
	);

	const state = useSyncExternalStore(
		store?.subscribe ?? (() => () => {}),
		store?.getSnapshot ?? (() => defaultState),
		store?.getSnapshot ?? (() => defaultState),
	);

	const start = useCallback(
		async (chatId: string) => {
			if (manager === null) return;

			await manager.start(chatId);
			store?.refresh();
		},
		[manager, store],
	);

	return { manager, store, state, start };
}
```

```ts
// The ringtone is generated: a repeating two-tone pattern, so the repository
// holds no audio file.
export interface Ringtone {
	stop(): void;
}

export function startRingtone(): Ringtone {
	const context = new AudioContext();
	const oscillator = context.createOscillator();
	const gain = context.createGain();

	oscillator.type = "sine";
	oscillator.frequency.value = 440;
	gain.gain.value = 0.05;

	oscillator.connect(gain);
	gain.connect(context.destination);
	oscillator.start();

	let stopped = false;

	const timer = setInterval(() => {
		if (stopped) return;

		oscillator.frequency.value = oscillator.frequency.value === 440 ? 660 : 440;
	}, 800);

	return {
		stop() {
			if (stopped) return;

			stopped = true;
			clearInterval(timer);
			oscillator.stop();
			void context.close();
		},
	};
}
```

The `register` helper goes through the API: the development configuration

```ts
async function register(
	request: import("@playwright/test").APIRequestContext,
	baseURL: string,
	email: string,
	nick: string,
): Promise<string> {
	const code = await request.post(`${baseURL}/api/auth/send-code`, {
		data: { email },
	});

	const sent = await code.json();
	const debugCode = sent.debugCode as string;

	const verified = await request.post(`${baseURL}/api/auth/verify-code`, {
		data: { email, code: debugCode },
	});

	const verifiedBody = await verified.json();

	if (verifiedBody.setupToken !== undefined) {
		const completed = await request.post(
			`${baseURL}/api/auth/complete-registration`,
			{ data: { setupToken: verifiedBody.setupToken, nick } },
		);

		const completedBody = await completed.json();

		return completedBody.token as string;
	}

	return verifiedBody.token as string;
}
```

**Deliberate decisions taken while writing the plan**

- The service sends the events through a narrow `eventSender` interface
  instead of the concrete `*sse.Hub`, so the rules can be tested without a
  hub. The real hub satisfies the interface unchanged.
- The registry keeps the offer only while the call is ringing and clears both
  SDP strings when the call ends, so a finished call holds no SDP.
- The e2e test registers the users through the API instead of the interface:
  the development configuration returns the verification code, which makes
  the test independent of the translation keys of the login page.
